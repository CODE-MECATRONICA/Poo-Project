Constructores y toString()

Los constructores permiten inicializar objetos y el método toString() permite mostrar información en formato texto.

Constructores

Los constructores se ejecutan automáticamente cuando se crea un objeto.

Ejemplo 1

public Persona(){

}

Ejemplo 2

public Persona(String nombre){

}

Ejercicios

  • Crear un constructor vacío.
  • Crear un constructor con parámetros.

toString()

El método toString() convierte un objeto en texto para mostrar información organizada.

Ejemplo 1

public String toString(){

    return nombre;

}

Ejemplo 2

System.out.println(persona);

Ejercicios

  • Implementar toString().
  • Mostrar datos de un objeto.
