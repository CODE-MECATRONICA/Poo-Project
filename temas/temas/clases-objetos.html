Clases y Objetos en Java

Las clases son plantillas que permiten crear objetos. Los objetos representan entidades con atributos y métodos.

Ejemplo 1

class Carro{
    String marca;
}

Ejemplo 2

Carro c = new Carro();

Ejercicios

  • Crear una clase llamada Animal.
  • Crear un objeto tipo Computador.
