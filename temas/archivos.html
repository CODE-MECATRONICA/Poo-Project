Lectura de Archivos

La lectura de archivos permite obtener información almacenada dentro de archivos .txt o .csv para utilizarla en un programa.

Java incluye clases como FileReader y BufferedReader para facilitar este proceso.

Ejemplo 1

FileReader archivo;

Ejemplo 2

BufferedReader lector;

Ejercicios

  • Leer un archivo .txt.
  • Mostrar datos desde un archivo.

Escritura de Archivos

La escritura de archivos permite guardar información de manera permanente dentro de un sistema.

Java utiliza clases como FileWriter y BufferedWriter para crear y modificar archivos.

Ejemplo 1

FileWriter escritor;

Ejemplo 2

escritor.write("Hola");

Ejercicios

  • Crear un archivo .csv.
  • Guardar datos en un archivo.
