Lectura y Escritura de Archivos

Java permite trabajar con archivos para guardar y leer información dentro de una aplicación.

Las clases FileReader, BufferedReader y FileWriter facilitan el manejo de archivos .txt y .csv.

Lectura de Archivos

Ejemplo 1

FileReader archivo;

Ejemplo 2

BufferedReader lector;

Ejercicios

  • Leer un archivo .txt.
  • Mostrar datos desde un archivo.

Escritura de Archivos

Ejemplo 1

FileWriter escritor;

Ejemplo 2

escritor.write("Hola");

Ejercicios

  • Crear un archivo .csv.
  • Guardar datos en un archivo.
