Lectura y Escritura de Archivos

Java permite trabajar con archivos para almacenar y recuperar información.

Lectura de Archivos

La lectura de archivos permite obtener información guardada en archivos .txt o .csv.

Ejemplo 1

FileReader archivo;

Ejemplo 2

BufferedReader lector;

Ejercicios

  • Leer un archivo .txt.
  • Mostrar datos desde un archivo.

Escritura de Archivos

La escritura de archivos permite guardar información de forma permanente.

Ejemplo 1

FileWriter escritor;

Ejemplo 2

escritor.write("Hola");

Ejercicios

  • Crear un archivo .csv.
  • Guardar datos en un archivo.
