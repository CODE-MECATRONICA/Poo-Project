Excepciones

Las excepciones permiten detectar y controlar errores durante la ejecución de un programa.

Gracias al manejo de excepciones es posible evitar que la aplicación se cierre inesperadamente.

Ejemplo 1

try{

}catch(Exception e){

}

Ejemplo 2

catch(ArithmeticException e){

}

Ejercicios

  • Crear un bloque try-catch.
  • Manejar una división entre cero.

throw, throws y finally

throw y throws permiten generar y declarar excepciones, mientras que finally ejecuta instrucciones obligatorias.

Estas herramientas ayudan a controlar errores de forma segura.

Ejemplo 1

throw new Exception();

Ejemplo 2

finally{

}

Ejercicios

  • Usar throw en un método.
  • Agregar finally a un programa.
