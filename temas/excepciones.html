Manejo de Excepciones

Las excepciones permiten manejar errores durante la ejecución del programa.

Ejemplo 1

try{
    int a = 5/0;
}catch(Exception e){
    System.out.println("Error");
}

Ejemplo 2

throw new Exception("Error");

Ejercicios

  • Crear un bloque try-catch.
  • Investigar finally y throws.
