Composición

La composición ocurre cuando una clase contiene objetos de otra clase dentro de su estructura.

Este principio ayuda a construir programas más organizados y facilita la reutilización de componentes.

Ejemplo 1

class Motor{

}

class Carro{
    Motor motor;
}

Ejemplo 2

class Universidad{
    Estudiante estudiante;
}

Ejercicios

  • Relacionar Libro con Autor.
  • Crear una clase Computador con Procesador.

Modularización

La modularización divide un programa en diferentes módulos o paquetes para facilitar su organización.

Esto mejora la lectura del código y el trabajo en equipo.

Ejemplo 1

package modelos;

Ejemplo 2

package servicios;

Ejercicios

  • Separar clases en paquetes.
  • Organizar un proyecto en módulos.
