Composición y Modularización

La composición ocurre cuando una clase contiene objetos de otra clase dentro de su estructura.

La modularización divide el programa en partes más pequeñas para mejorar la organización y mantenimiento del código.

Composición

Ejemplo 1

class Motor{

}

class Carro{
    Motor motor;
}

Ejemplo 2

class Universidad{
    Estudiante estudiante;
}

Ejercicios

  • Relacionar Libro con Autor.
  • Crear una clase Computador con Procesador.

Modularización

Ejemplo 1

package modelos;

Ejemplo 2

package servicios;

Ejercicios

  • Separar clases en paquetes.
  • Organizar un proyecto en módulos.
