Composición y Modularización

La composición ocurre cuando una clase contiene objetos de otra clase como parte de su estructura.

Ejemplo 1

class Motor{

}

class Carro{
    Motor motor = new Motor();
}

Ejemplo 2

class Universidad{
    Estudiante estudiante;
}
