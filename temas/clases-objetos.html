Clases y Objetos en Java

Las clases son plantillas que permiten definir las características y comportamientos de un objeto. En ellas se establecen atributos y métodos que representan una entidad dentro del programa.

Los objetos son instancias creadas a partir de una clase. Gracias a ellos es posible utilizar la información y los métodos definidos previamente.

Clase

Una clase organiza información y comportamientos relacionados. Sirve como base para crear múltiples objetos.

Ejemplo 1

class Persona{

    String nombre;
    int edad;

}

Ejemplo 2

class Carro{

    String marca;

    void encender(){
        System.out.println("Carro encendido");
    }

}

Ejercicios

  • Crear una clase llamada Animal.
  • Crear una clase llamada Computador.

Objeto

Un objeto es la representación real de una clase. Cada objeto puede almacenar datos diferentes.

Ejemplo 1

Persona persona1 = new Persona();

persona1.nombre = "Carlos";

Ejemplo 2

Carro carro1 = new Carro();

carro1.encender();

Ejercicios

  • Crear un objeto tipo Estudiante.
  • Crear dos objetos de una misma clase.
