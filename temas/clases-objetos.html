Clases y Objetos

Las clases y objetos son la base de la Programación Orientada a Objetos.

Clases

Las clases funcionan como plantillas para crear objetos.

Ejemplo 1

class Persona{

}

Ejemplo 2

class Carro{

}

Ejercicios

  • Crear una clase Animal.
  • Crear una clase Computador.

Objetos

Los objetos son instancias creadas a partir de una clase.

Ejemplo 1

Persona p = new Persona();

Ejemplo 2

Carro c = new Carro();

Ejercicios

  • Crear un objeto tipo Estudiante.
  • Crear dos objetos diferentes.
