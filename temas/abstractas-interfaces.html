Clases Abstractas e Interfaces

Las clases abstractas sirven como base para otras clases y no pueden crear objetos directamente.

Las interfaces permiten definir comportamientos que otras clases deben implementar.

Clases Abstractas

Ejemplo 1

abstract class Figura{

}

Ejemplo 2

abstract void calcularArea();

Ejercicios

  • Crear una clase abstracta Animal.
  • Definir un método abstracto.

}

Ejemplo 2

void acelerar();
