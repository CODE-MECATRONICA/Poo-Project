Clases Abstractas e Interfaces

Las clases abstractas sirven como base para otras clases. Las interfaces definen comportamientos obligatorios.

Ejemplo 1

abstract class Figura{
    abstract void area();
}

Ejemplo 2

interface Animal{
    void sonido();
}

Ejercicios

  • Crear una interfaz llamada Vehiculo.
  • Crear una clase abstracta Persona.
