Polimorfismo

El polimorfismo permite que un método tenga diferentes comportamientos dependiendo del objeto.

Ejemplo 1

class Animal{
    void sonido(){
        System.out.println("Sonido");
    }
}

class Gato extends Animal{
    void sonido(){
        System.out.println("Miau");
    }
}

Ejemplo 2

Animal a = new Gato();
a.sonido();
