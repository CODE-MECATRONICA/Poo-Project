Herencia en Java

La herencia permite que una clase herede atributos y métodos de otra clase. Esto ayuda a reutilizar código y organizar mejor los programas.

En Java se utiliza la palabra extends y el método super() para trabajar con herencia.

Herencia

Ejemplo 1

class Animal{

}

class Perro extends Animal{

}

Ejemplo 2

class Persona{

}

class Estudiante extends Persona{

}

Ejercicios

  • Crear una clase Vehiculo y una clase Moto.
  • Heredar atributos de otra clase.

Uso de super()

Ejemplo 1

super(nombre);

Ejemplo 2

super();

Ejercicios

  • Usar super() en un constructor.
  • Llamar métodos de la clase padre.
