Herencia

La herencia es un principio de la Programación Orientada a Objetos que permite que una clase herede atributos y métodos de otra clase. Esto ayuda a reutilizar código y facilita la organización de los programas.

La clase que hereda se conoce como clase hija y la clase principal se conoce como clase padre.

Ejemplo 1

class Animal{

}

class Perro extends Animal{

}

Ejemplo 2

class Persona{

}

class Estudiante extends Persona{

}

Ejercicios

  • Crear una clase Vehiculo y una clase Moto.
  • Heredar atributos de otra clase.

super()

La palabra super() permite acceder a constructores y métodos de la clase padre desde la clase hija.

Se utiliza principalmente para reutilizar información heredada.

Ejemplo 1

super(nombre);

Ejemplo 2

super();

Ejercicios

  • Usar super() en un constructor.
  • Llamar un método de la clase padre.
