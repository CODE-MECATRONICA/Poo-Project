Herencia en Java

La herencia permite que una clase herede atributos y métodos de otra clase. Esto ayuda a reutilizar código.

Ejemplo 1

class Animal{
    void sonido(){
        System.out.println("Sonido");
    }
}

class Perro extends Animal{

}

Ejemplo 2

class Persona{
    String nombre;
}

class Estudiante extends Persona{
    int semestre;
}

Ejercicios

  • Crear una clase Vehiculo y una clase Moto.
  • Usar super() en un constructor.
