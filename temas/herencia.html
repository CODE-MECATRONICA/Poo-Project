Herencia en Java

La herencia permite reutilizar código mediante clases padre e hijas dentro de la Programación Orientada a Objetos.

Herencia

La herencia permite que una clase herede atributos y métodos de otra clase.

Ejemplo 1

class Animal{

}

class Perro extends Animal{

}

Ejemplo 2

class Persona{

}

class Estudiante extends Persona{

}

Ejercicios

  • Crear una clase Vehiculo.
  • Aplicar herencia entre clases.

super()

super() permite acceder a constructores y métodos de la clase padre.

Ejemplo 1

super(nombre);

Ejemplo 2

super();

Ejercicios

  • Usar super() en un constructor.
  • Llamar métodos heredados.
