Introducción a la POO

La Programación Orientada a Objetos permite desarrollar software utilizando clases y objetos para organizar mejor los programas.

Programación Orientada a Objetos

La POO facilita la reutilización del código y mejora la organización de aplicaciones complejas.

Ejemplo 1

class Persona{

}

Ejemplo 2

Persona p = new Persona();

Ejercicios

  • Crear una clase Animal.
  • Crear un objeto tipo Libro.

JDK

El JDK contiene herramientas necesarias para desarrollar programas en Java.

Ejemplo 1

javac Main.java

Ejemplo 2

java Main

Ejercicios

  • Investigar herramientas del JDK.
  • Compilar un programa Java.
