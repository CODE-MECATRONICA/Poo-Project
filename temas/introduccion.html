Programación Orientada a Objetos

La Programación Orientada a Objetos organiza los programas mediante clases y objetos para facilitar el desarrollo de software.

Ejemplo 1

class Persona{

}

Ejemplo 2

Persona p = new Persona();

Ejercicios

  • Crear una clase llamada Animal.
  • Crear un objeto tipo Libro.

JDK

El JDK contiene herramientas necesarias para desarrollar programas en Java.

Ejemplo 1

javac Main.java

Ejemplo 2

java Main

Ejercicios

  • Investigar herramientas del JDK.
  • Compilar un programa Java.
