Introducción a la Programación Orientada a Objetos

La Programación Orientada a Objetos (POO) es un paradigma de programación que organiza el software mediante clases y objetos. Este enfoque permite desarrollar aplicaciones más ordenadas, reutilizables y fáciles de mantener. En Java, la POO es fundamental porque el lenguaje está diseñado para trabajar principalmente con objetos y relaciones entre ellos.

Entorno de desarrollo en Java

Para desarrollar programas en Java se utilizan herramientas como el JDK, que contiene los compiladores y bibliotecas necesarias; la JVM, que permite ejecutar programas Java en diferentes sistemas operativos; y entornos de desarrollo como IntelliJ IDEA, Eclipse, NetBeans o VS Code, que facilitan la escritura y organización del código.

Ejemplo 1

class Persona{
    String nombre;
}

Ejemplo 2

Persona p = new Persona();
