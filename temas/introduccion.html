Introducción a la Programación Orientada a Objetos

La Programación Orientada a Objetos es un paradigma de programación que organiza el código utilizando objetos y clases. Permite desarrollar programas más organizados, reutilizables y fáciles de mantener.

Entorno de desarrollo en Java

Java necesita herramientas como el JDK y la JVM para compilar y ejecutar programas. Además, existen IDEs como IntelliJ IDEA, Eclipse, NetBeans y VS Code.

Ejemplo 1

class Persona{
    String nombre;
}

Ejemplo 2

Persona p = new Persona();

Ejercicios propuestos

  • Crear una clase llamada Estudiante.
  • Investigar las diferencias entre JDK y JVM.
