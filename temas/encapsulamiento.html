Atributos, Métodos y Encapsulamiento

Los atributos almacenan información y los métodos representan acciones dentro de una clase. El encapsulamiento protege los datos utilizando modificadores de acceso.

Los getters y setters permiten acceder y modificar atributos de manera controlada.

Atributos

Ejemplo 1

String nombre;

Ejemplo 2

int edad;

Ejercicios

  • Crear atributos para una clase Libro.
  • Agregar atributos a una clase Animal.

Ejemplo 1

void saludar(){

}

Ejercicios

Encapsulamiento

Ejemplo 1

private String nombre;

Ejemplo 2

public String getNombre(){
    return nombre;
}
