List

List permite almacenar elementos de forma ordenada y repetida dentro de una colección.

Una de las implementaciones más utilizadas es ArrayList.

Ejemplo 1

ArrayList lista;

Ejemplo 2

lista.add("Juan");

Ejercicios

  • Crear una lista de estudiantes.
  • Agregar elementos a un ArrayList.

Map

Map almacena datos mediante claves y valores.

Permite acceder rápidamente a la información utilizando una clave específica.

Ejemplo 1

HashMap mapa;

Ejemplo 2

mapa.put(1,"Carlos");

Ejercicios

  • Crear un HashMap.
  • Guardar datos usando claves.

Set

Set almacena elementos sin permitir valores repetidos.

Es útil cuando se necesita trabajar con datos únicos.

Ejemplo 1

HashSet datos;

Ejemplo 2

datos.add("Java");

Ejercicios

  • Crear un HashSet.
  • Agregar datos sin repetir.
