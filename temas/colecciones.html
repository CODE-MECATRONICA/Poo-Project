Colecciones y Estructuras de Datos

Las colecciones permiten almacenar grupos de datos de forma dinámica y organizada.

List

List almacena elementos de forma ordenada y permite datos repetidos.

Ejemplo 1

ArrayList lista;

Ejemplo 2

lista.add("Juan");

Ejercicios

  • Crear una lista de estudiantes.
  • Agregar elementos a un ArrayList.

Map

Map almacena datos mediante claves y valores.

Ejemplo 1

HashMap mapa;

Ejemplo 2

mapa.put(1,"Carlos");

Ejercicios

  • Crear un HashMap.
  • Guardar datos usando claves.

Set

Set almacena elementos sin permitir datos repetidos.

Ejemplo 1

HashSet datos;

Ejemplo 2

datos.add("Java");

Ejercicios

  • Crear un HashSet.
  • Agregar datos únicos.
