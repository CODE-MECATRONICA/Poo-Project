Introducción a la Programación Orientada a Objetos

La Programación Orientada a Objetos (POO) es un paradigma de programación basado en objetos que contienen datos y métodos.

Ejemplo 1

class Persona{
    String nombre;
}

Ejemplo 2

Persona p = new Persona();

Ejercicios

  • Crear una clase llamada Estudiante.
  • Crear un objeto tipo Vehículo.
